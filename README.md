# PERSEUS reproducibility artifact

PERSEUS: Planner-Aware Evidence-Gated Residual Selection for Estimator Updates under Shift.

This release contains the estimator, admission, and optimizer experiment code; recorded per-query predictions and timings; fitting/tuning/gating/test memberships; per-split results; uncertainty analyses; and the PostgreSQL 13.1 row-estimation callback source. The release identifier is `2026-10-03-anonymous-1`.

## Start here

```powershell
python -m pip install -r requirements-saved.txt
python tools/verify_saved_results.py
```

This command checks exported file hashes, recomputes candidate and admitted/fallback q-error statistics from saved predictions, checks SQL-grouped roles, and verifies all 6,480 throughput requests and their measured block goodput. It writes its report outside the artifact by default and does not train a model or contact a database.

To recompute the paired SQL-cluster confidence intervals for the residual HGB results:

```powershell
python tools/verify_saved_results.py --bootstrap
```

## Training and replay

The exact recorded entry points, execution order, and clean-directory instructions are in [REPRODUCE.md](REPRODUCE.md). Saved observations are retained intact: runners deliberately refuse to overwrite them.

The exported Python sources remove local workspace prefixes and password defaults. `provenance/export_manifest.json` distinguishes the hashes of the actual experiment-time bytes from the hashes of the exported bytes. Historical manifests refer to the experiment-time files; the release verifier checks the exported files. Newly replicated runs produce their own manifests.

Source MSCN checkpoints, workload query CSVs, reconstructed sample bitmaps, neural control checkpoints, and saved prediction arrays are included. Fitted tree-model pickles can be regenerated by the supplied training code; their original hashes are listed in the export manifest. PostgreSQL database installations, data directories, private reviewer correspondence, and the author-identified manuscript are excluded.

## Upstream sources and terms

The baseline source and workload definitions derive from [Workload-Drift-Benchmark](https://github.com/mzz235711/Workload-Drift-Benchmark). The local source revision is recorded in the manifest. MSCN retains its upstream MIT license at `baselines/workload-drift-benchmark/baselines/MSCN-modified/LICENSE`.

The planner experiment uses PostgreSQL 13.1 and the [End-to-End-CardEst-Benchmark](https://github.com/Nathaniel-Han/End-to-End-CardEst-Benchmark) integration. PostgreSQL's terms accompany the callback overlay. STATS and IMDb database rows must be obtained through the corresponding benchmark sources and loaded for new DBMS runs.

PERSEUS-specific code retains the supplied research/review-use terms in [LICENSE](LICENSE). This release does not change third-party licenses.
